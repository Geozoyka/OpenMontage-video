# Промпты героев, версия 3 (упрощённый войлок)

Модель: Nano Banana Pro. Порядок: Тоби → Мия (эталон Тоби) → мама-собака (эталон Тоби) → мама-кошка (эталон Мии).

## Защита от ошибок Nano Banana

- Надписи на листе → слова «character sheet» и «front view» убраны; герой снят как фото ряда фигурок, на фото подписей не бывает.
- Уши и хвост «гуляют» между картинками → описаны как деталь, пришитая мастером намертво.
- Встаёт на две лапы → «four-legged», «on all four paws» в каждой позе.
- Розовое ухо внутри → «solid felt on both sides».
- Глаза становятся аниме или «пуговицами» → размер задан долей лица, один блик.
- Гладкая шерсть уходит в пластилин → «tightly felted wool ball, soft fuzzy edge».
- Эмоции слабые → каждая эмоция описана через брови, позу, хвост.
- Детали одного героя переходят к другому → каждый герой отдельным запросом, мамы с одним малышом для масштаба.
- Стиль и размер меняются между запросами → лист Тоби загружается эталоном во все следующие.
