# Голоса героев в ElevenLabs — раздел Sound Effects

Где: elevenlabs.io → меню слева → Sound Effects (Звуковые эффекты).
Не раздел Text to Speech: он делает речь, а не звуки животных.

Настройки:
- Duration (длительность): задать вручную — 1–2 с для лая и мяуканья, 5–8 с для мурлыканья.
- Prompt influence (точность следования промпту): 0.6. Выше — звук становится искусственным, ниже — сервис фантазирует.
- Loop (зацикливание): включать только для мурлыканья.
- Каждый запрос даёт несколько вариантов. Выбрать 1–2 лучших на каждую эмоцию.
- Имена файлов: toby_happy_01, mia_purr_01 и т. д.

Права: на бесплатном тарифе коммерческое использование запрещено и требуется указание авторства. Для канала с монетизацией генерировать на платном тарифе (Starter и выше). Перед оплатой проверьте условия.

Правило одного голоса: в каждом промпте героя повторяется одна и та же фраза-описание голоса. Это приближает звуки друг к другу; окончательно тембр подгоняет Claude при сведении.
