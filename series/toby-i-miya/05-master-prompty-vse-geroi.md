# Мастер-промпты: все герои, двор, солнышко (итог всех проб)

Каждый промпт самодостаточный: работает и без загруженных картинок. Если в сервисе можно загрузить образец (в Krea: Image prompt / Style reference), загружайте утверждённый лист этого же героя — сходство будет выше.

Порядок: Тоби → Мия → мама-собака → мама-кошка → двор → солнышко.

## Какие ошибки уже были и чем закрыты

1. Надписи и подписи на листе → «wordless page, only drawings», без слов «character sheet» и «view labels».
2. Герой встаёт на задние лапы → «four-legged, always on four paws».
3. Ухо Тоби «гуляет» (оба висят, стоячее меняет сторону, в грусти длинные уши) → уши описаны как неизменная черта, сторона задана, эмоции только бровями/ртом/позой.
4. Типовой «фотобанковый» щенок → голова-булочка шире, чем высота, больше тела; ножки-палочки; неровная линия фломастера.
5. Чёрный контур, тени, градиенты → цветной контур на тон темнее, только плоская заливка.
6. Мия выходит серой → «creamy white, never grey» + код цвета.
7. Пятна Мии «гуляют», пропадает белый кончик хвоста → ровно три пятна с постоянным местом, кончик хвоста задан.
8. Мамы выглядят как малыши → взрослые пропорции: голова меньше относительно тела, морда длиннее, ноги длиннее, глаза меньше, ресницы.
9. Сонные или подозрительные глаза мам → приподнятые нижние веки («улыбка глазами»), без полуопущенных верхних.
10. Предупреждение выходит грустным → брови ровные, рот прямой, взгляд спокойный.
11. Малыш рядом с мамой разного размера → «голова малыша достаёт маме до плеча» на всех рисунках.
12. Помесь Тоби и Мии рядом с мамой → малыш описан полностью внутри промпта мамы; не загружать лист чужой семьи.
13. Мама-кошка слишком похожа на Мию → «негатив» Мии: угольная с белой маской.
14. Лишнее коричневое пятно, «котёнок без головы», закрытая морда мамы → «only charcoal and white», каждый герой целиком, обе морды видны.
15. Разный цвет глаз → «both eyes the same mint green in every drawing».
16. «Аниме»-глаза в ChatGPT → глаза: белые овалы с маленькими зрачками.
17. Двор: обрезанное дерево → дерево целиком внутри кадра с запасом неба.
18. Двор: забор и будка цвета Тоби → серо-голубые.
19. Двор: дорожка через середину, коврик на траве → дорожка по дальнему краю, коврик на ступеньке, середина пустая.
20. Двор: животные в кадре → «empty yard, only nature and objects».
21. Солнце во дворе → левый верх неба оставлен пустым: солнышко ставится отдельным слоем.

## Если ошибка всё же проскочила — правка, а не новая генерация

- Надписи: `Remove all text and labels from this image. Keep everything else exactly the same.`
- Уши Тоби: `In the drawing [номер/место], make one ear stand straight up on the viewer's right and the other fold down, exactly like in the first drawing. Keep everything else exactly the same.`
- Цвет глаз: `Make both eyes of [героя] in every drawing the same mint green as in the first drawing. Keep everything else exactly the same.`
- Серая Мия: `Change the grey fill of the white areas to warm creamy white (#FBF4E6). Keep everything else exactly the same.`
- Обрезанное дерево во дворе: `Zoom out slightly so the whole apple tree with its full crown fits inside the picture with sky above it. Keep the style and everything else the same.`
